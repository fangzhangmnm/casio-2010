GWHBOB 的计算器程序

fx-9750GII（刷 9860 系统）· 卡西欧 BASIC 和 C · 2010–2013 · 当年发在 cnCalc 计算器论坛的原件

键帽下面的黄字 = 这一刻按它会怎样；变暗的键这一刻没用。程序列表：在屏幕上拖动滚动，点一下选中，再点一下运行。

这个壳做了什么、没做什么
  • BASIC 程序跑的是当年论坛附件里的 G1M 原始字节，没改一个字；页面打开时现场解码。解释器只实现了这几个程序用到的卡西欧 BASIC（If / While / For / Goto、Prog、Locate、Getkey、List / Mat、复数 i、字符串、⇒、Stop 等）。三国杀、塔防用到画图指令，还跑不了。BASIC 的速度按每秒约 600 行估，没有对过真机。
  • 魔塔、Doodle Jump、3D 引擎是 C 写的 Add-in（G1A）：当年的源码一个字不改，连同一层模拟卡西欧 SDK 的壳编成 WebAssembly。存档存在这个浏览器里。
  • 字体取自卡西欧 fx-9860G SDK 的字符码表（2007）：大字体逐点采样（P–Z、p–z 等几个采样错位的照标准 5×7 补），小字体取第 7 页；字形位置对过 2012 年的截图。
  • 屏幕颜色取自那台计算器的照片；液晶残影按 0.15 秒估。
