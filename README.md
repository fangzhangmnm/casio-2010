# casio-2010 · GWHBOB 的卡西欧计算器程序（2010–2013）

GWHBOB 2010–2013 年在卡西欧 fx-9750GII（刷 9860 系统）上写的程序，2026 年复活成网页，在浏览器里就能玩。

**在线玩**：https://fangzhangmnm.github.io/casio-2010/ （合集页；每个游戏也有自己的网页，打开就玩，比如魔塔 https://fangzhangmnm.github.io/casio-2010/play/magtower.html ）

## 下载

- **整个仓**：GitHub 页面右上角「Code → Download ZIP」，源码、原件、文档都在里面。
- **装到计算器上**：程序在各展厅的 `originals/`——`.G1M` 是卡西欧 BASIC，`.G1A` 是 Add-in（要刷 9860 系统的机器，或者能装 Add-in 的型号）。魔塔还要把 `20120703 魔塔/originals/HZK12.df`（中文字库）放进存储内存。
